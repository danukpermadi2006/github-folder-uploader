Info Keamanan & Cara Dapat Token

Aplikasi ini membutuhkan Personal Access Token (Classic) GitHub. Ikuti langkah mudah ini:

  1. Buka halaman GitHub Tokens lalu klik tombol Generate new token (classic).
  2. Isi kolom Note (contoh: "Web Uploader") dan atur masa kedaluwarsa (Expiration) sesuai kebutuhan.
  3. Pada bagian daftar izin (Select scopes), Anda wajib mencentang dua kotak berikut:
    • repo Memberi akses penuh untuk mengunggah file dan membuat repositori baru.
    • delete_repo Memberi akses khusus untuk menghapus repositori.
  4. Gulir ke paling bawah halaman, lalu klik tombol hijau Generate token.
  5. Salin (Copy) token yang berawalan ghp_... dan tempelkan ke kolom GitHub Token di bawah ini.

Token Anda tidak pernah disimpan di server mana pun. Seluruh proses komunikasi dengan API GitHub dilakukan langsung dan secara lokal dari browser Anda.
