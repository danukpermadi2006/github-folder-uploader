Info Keamanan & Cara Dapat Token

Aplikasi ini membutuhkan Personal Access Token (Classic) GitHub. Ikuti langkah mudah ini:

  1. Buka halaman GitHub Tokens lalu klik tombol Generate new token (classic).
  2. Isi kolom Note dan atur masa kedaluwarsa (Expiration).
  3. Pada bagian daftar izin (Select scopes), Anda wajib mencentang dua kotak berikut:
    • repo Memberi akses penuh untuk mengedit, mengunggah file, dan membuat repositori.
    • delete_repo Memberi akses khusus untuk menghapus repositori.
  4. Klik Generate token lalu salin token tersebut.
