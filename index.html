Info Keamanan & Cara Dapat Token

Aplikasi ini membutuhkan Personal Access Token (Classic) GitHub. Ikuti langkah mudah ini:

  1. Buka halaman GitHub Tokens. Klik Generate new token (classic).
  2. Pilih scopes: repo (akses edit/upload) dan delete_repo (akses hapus repo).
  3. Generate dan salin token tersebut ke form di bawah.
Peringatan: Jika Anda menggunakan perangkat publik (warnet/komputer teman), JANGAN centang kotak "Remember". Selalu gunakan tombol "Disconnect" setelah selesai agar token Anda tidak tersimpan di browser.
